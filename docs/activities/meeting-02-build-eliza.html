Build ELIZA together

ELIZA was a program from 1966 that seemed to hold a conversation. It only followed rules written by hand: if the message contains a certain word, give a certain reply. Today the class writes the rules.

1. Write one rule

Example: if the message contains “exam”, reply “How do you feel about the exam?” Keep to everyday topics.

2. Talk to the class’s program

It knows 0 rules. Try to get a reply that makes no sense.

Program: Hello. How are you today?

Recap

  • The program finds a keyword and gives the reply written for it. It has no idea what the message is about.
  • People still felt that ELIZA understood them. Much of the meaning came from the person reading the replies.
  • Today’s chatbots do not use hand-written rules like these. They predict text. That is next.
