A language model writes one word at a time. For each word it has a list of likely next words, and it picks one. Today the class is the model: everyone suggests the next word, and one word is chosen from all the answers.

Recap

  • For each word, the class had a spread of answers: a few common ones and many rare ones. A language model has the same kind of list.
  • Taking the top word every time gives a safe, expected sentence.
  • Drawing a word at random gives a different sentence each time. Chatbots do this, which is why the same question can get different answers.
